Admin login

Username / password কোথায় সেট করব?

Windows PowerShell-এ নিচের মানগুলো বসিয়ে একই উইন্ডোতে সার্ভার চালান:

$env:ADMIN_USERNAME = "আপনার ইউজারনেম"
$env:ADMIN_PASSWORD = "আপনার পাসওয়ার্ড"
$env:FLASK_SECRET_KEY = [guid]::NewGuid().ToString('N')
python app.py

PowerShell উইন্ডো বন্ধ হলে আবার সেট করতে হবে।
