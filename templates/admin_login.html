How do I set the username and password?

Set these values in Windows PowerShell, then start the server in the same window:

$env:ADMIN_USERNAME = "your-username"
$env:ADMIN_PASSWORD = "your-password"
$env:FLASK_SECRET_KEY = [guid]::NewGuid().ToString('N')
python app.py

Set them again whenever you open a new PowerShell window.
